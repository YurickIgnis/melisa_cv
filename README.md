# Portafolio digital de Melisa

Sitio web estático, responsive y accesible para GitHub Pages.

## Estado del contenido
**Versión inicial de diseño.** La foto y la información profesional auténtica de Melisa todavía no han sido proporcionadas en esta conversación. Por ello, los espacios de trayectoria, educación, herramientas y proyectos contienen marcadores explícitos y no deben confundirse con datos reales.

## Archivos
- `index.html`: estructura semántica, contenido y metadatos
- `styles.css`: identidad visual y vistas adaptables
- `app.js`: menú, animaciones, modal de proyectos, progreso y PDF
- `favicon.svg`: icono de marca provisional

## Publicar con GitHub Pages
En GitHub > Settings > Pages, seleccionar **Deploy from a branch** > `main` > `/(root)`, y guardar. La URL prevista, una vez activado el despliegue, es `https://yurickignis.github.io/melisa_cv/`.

## Antes de compartir como CV definitivo
Añadir nombre completo, titular profesional, experiencia, educación, proyectos comprobables, habilidades y fotografía que la titular haya autorizado publicar. Evitar publicar domicilio, identificación oficial, fecha de nacimiento o teléfono personal sin necesidad.
